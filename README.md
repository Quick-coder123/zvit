# Неоновий Бастіон

Кооперативний sci-fi **tower defense з героями** у 3D для трьох гравців: спільна база, особисті герої, грінд і прокачка. Хвилі ворогів стають сильнішими з кожним номером **незалежно від вашого рівня**. Сила ворогів не підлаштовується під гравців: що швидше прокачуєтесь, то легше відбиватися.

Гра працює повністю офлайн. Інтернет потрібен лише один раз, щоб зібрати програму.

---

## Як грати втрьох через RDP (одна копія гри на одному ПК)

1. Встановіть або розпакуйте гру в спільну папку, наприклад `C:\Games\NeonBastion\`.
2. Кожен гравець заходить на ПК через RDP під своїм обліковим записом Windows і запускає `NeonBastion.exe`.
3. **Перша запущена копія автоматично стає сервером (хостом).** Хост вибирає «Нова гра» або «Продовжити збереження», складність і час між нападами.
4. Друга й третя копії самі знаходять хост і підключаються. Імена героїв беруться з імен облікових записів Windows, тому кожен отримує свого героя з власною прокачкою.
5. Якщо хост вийде, інші копії автоматично перепідключаться, і одна з них стане новим хостом. Прогрес не втрачається.

**Збереження** лежать у спільній папці `C:\ProgramData\NeonBastion\` (`world.json` і резервна копія `world.backup.json`). Гра зберігається автоматично після кожної хвилі, щохвилини та під час виходу.

### Важливо для графіки через RDP

За замовчуванням Windows може не давати RDP-сесіям відеокарту, і тоді 3D рендериться процесором (повільно). На хост-ПК увімкніть:

`gpedit.msc` → Конфігурація комп'ютера → Адміністративні шаблони → Компоненти Windows → Служби віддалених робочих столів → Вузол сеансів віддалених робочих столів → Середовище віддаленого сеансу →
**«Використовувати апаратний графічний адаптер за замовчуванням для всіх сеансів служб віддалених робочих столів»** → *Увімкнено*.

(англ.: *Use hardware graphics adapters for all Remote Desktop Services sessions*). Після цього перезапустіть ПК. Якщо гра однаково гальмує, знизьте якість у меню **Esc → Налаштування** (Низька / Середня / Висока / Ультра).

> Windows 10/11 Pro без серверної ліцензії RDS пускає лише одну RDP-сесію одночасно. Для трьох одночасних сесій потрібна Windows Server з RDS або аналогічне рішення.

### Альтернатива: гра по локальній мережі з різних ПК

На хост-ПК просто запустіть гру. На інших ПК запустіть із параметром IP-адреси хоста:

```
NeonBastion.exe --host=192.168.1.10
```

Брандмауер хоста має пропускати TCP-порт **47621**. Також можна відкрити `http://IP-хоста:47621` у Chrome або Edge.

## Як отримати .exe

### Варіант 1: готова збірка з GitHub Actions
Після кожного push GitHub автоматично збирає гру під Windows: вкладка **Actions** → «Збірка Windows .exe» → останній запуск → **Artifacts → NeonBastion-windows**. Усередині портативний `.exe` (запускається без встановлення) і `.zip`.

### Варіант 2: зібрати самостійно на Windows
1. Встановіть [Node.js 22 LTS](https://nodejs.org/).
2. У папці проєкту:
   ```
   npm install
   npm run dist
   ```
3. Готові файли з'являться в `dist\`.

Запуск без збирання: `npm install`, потім `npm start`.
Тільки сервер без вікна (гравці заходять через браузер): `npm run server`.

## Ігровий цикл

**Підготовка → Напад → Підготовка…** Тривалість підготовки задається в меню (1–15 хв).

Під час підготовки:
- **Зачищайте табори** за периметром бази. Кожна зачистка підвищує рівень табору, тож наступного разу там сильніші монстри й кращий лут. Табори далі від бази мають вищий стартовий рівень.
- **Збирайте лут:** спорядження п'яти рідкостей (Звичайний → Незвичайний → Рідкісний → Епічний → Легендарний). Непотрібне продавайте за кредити або розбирайте на кристали.
- **Будуйте шахти** на 6 родовищах кристалів і покращуйте їх.
- **Будуйте й покращуйте вежі** (до 25 рівня).
- **Досліджуйте технології** за кристали: нові вежі, бонуси шкоди, економіка, ядро, герої.

**Вежі:** Бластер · Кріопроектор (сповільнення) · Дуговий вузол (ланцюгова блискавка) · Рейкотрон (пробиває лінію) · Плазмова мортира (площа, лише наземні) · Фазовий лазер (розпікається на цілі).

**Вороги:** Повзун, Бігун, Рій, Громило (броня), Шершень (літає повз дороги), Щитоносець (щит), Медик (лікує інших). **Кожна 10-та хвиля приводить боса:** Титан, Матка рою, Вартовий порожнечі.

**Герої** однакові на старті, а роль формується талантами з трьох гілок:
- **Штурмовик:** здоров'я, броня, вампіризм, таранний ривок.
- **Стрілець:** шкода, швидкострільність, крити, пробиття, граната.
- **Технік:** аура підсилення веж, бойовий дрон, ремонт ядра, знижки, орбітальний удар.

Рівень героя необмежений, кожен рівень дає очко таланту. Таланти можна скинути за кристали.

**Якщо ядро впаде:** команда втрачає 25% кредитів і кристалів, хвиля повторюється. Рівні, спорядження, вежі й дослідження зберігаються.

**Складність** вибирається на старті нової гри й визначає, як швидко ростуть вороги: Легко ≈ +7% за хвилю, Нормально ≈ +9%, Жорстко ≈ +11% (плюс лінійна надбавка). Без грінду команда зазвичай застрягає між 30 і 50 хвилями на «Нормально». Активний грінд таборів і лут відсувають межу значно далі.

## Структура проєкту

```
electron/   – вікно програми; перша копія запускає сервер
server/     – авторитетна симуляція гри, мережа (WebSocket), збереження
shared/     – баланс і формули (вежі, вороги, таланти, лут, дослідження)
client/     – 3D-рендер (Three.js), ефекти, інтерфейс, звук
```

Уся графіка та звук генеруються процедурно, зовнішніх файлів ресурсів немає.
