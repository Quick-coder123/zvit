# Останній рубіж

Кооперативна гра на трьох: оборона позиції (tower defense + керовані бійці) у реалістичному сеттингу сучасної війни. Це степ з лісосмугами й зруйноване місто, де змінюються пори року й погода. Є прокачка, грінд і трофеї. Хвилі противника посилюються з кожним номером **незалежно від вашого рівня**, тому прокачка справді вирішує.

Гра працює повністю офлайн. Усі ресурси (фотоскановані текстури, небо, моделі) лежать у репозиторії.

---

## Як грати втрьох через RDP (одна копія гри на одному ПК)

1. Розпакуйте гру в спільну папку, наприклад `C:\Games\LastLine\`.
2. Кожен гравець заходить на ПК через RDP під своїм обліковим записом Windows і запускає `LastLine.exe`.
3. **Перша запущена копія автоматично стає сервером (хостом).** Хост вибирає «Нова гра» або «Продовжити», складність і час між нападами.
4. Друга й третя копії підключаються самі. Бійці прив'язані до імен облікових записів Windows, тож у кожного своя прокачка.
5. Якщо хост вийде, інші копії перепідключаться, і одна з них стане новим хостом без втрати прогресу.

**Збереження:** `C:\ProgramData\LastLine\world.json` (+ `world.backup.json`). Автозбереження після кожної хвилі, щохвилини й під час виходу. Гра сама дає всім обліковим записам ПК доступ на запис до цієї папки.

### Графіка через RDP
Щоб 3D рендерилося відеокартою, а не процесором, увімкніть на хост-ПК:
`gpedit.msc` → Конфігурація комп'ютера → Адміністративні шаблони → Компоненти Windows → Служби віддалених робочих столів → Вузол сеансів віддалених робочих столів → Середовище віддаленого сеансу → **«Використовувати апаратний графічний адаптер за замовчуванням для всіх сеансів…»** → *Увімкнено*. Потім перезавантажте ПК.

Якщо гальмує, змініть якість в **Esc → Налаштування** (Низька / Середня / Висока / Ультра). Низька вимикає тіні, траву й частину дерев.

Там само налаштування доступності:
- масштаб інтерфейсу (80–200%);
- сила тряски камери (0–100%);
- «Менше спалахів».

> Звичайна Windows 10/11 Pro пускає лише одну RDP-сесію одночасно. Для трьох одночасних сесій потрібна Windows Server з RDS або аналогічне рішення.

### Альтернатива: локальна мережа
На інших ПК запускайте `LastLine.exe --host=192.168.1.10` (IP хоста). Брандмауер хоста має пропускати TCP-порт **47621**.

## Як отримати .exe

**GitHub Actions:** після кожного push вкладка **Actions** → «Збірка Windows .exe» → **Artifacts → LastLine-windows** (портативний `.exe` і `.zip`).

**Самостійно на Windows** (Node.js 22 LTS): `npm install`, потім `npm run dist`. Готові файли з'являться в `dist\`. Запуск без збирання: `npm start`.

## Керування

| Клавіша | Дія |
|---|---|
| **WASD** | рух бійця |
| **ЛКМ** (утримувати) | вогонь у бік курсора |
| **Q / E / R** | ривок / граната / артудар |
| **1–6** | вибрати вогневу позицію для будівництва (ЛКМ поставити, ПКМ/Esc скасувати) |
| **ПКМ на позиції** | керування позицією: покращити (**U**) чи продати |
| **F** | біля покинутого складу: облаштувати або покращити майстерню |
| **G** | «Готові» (якщо готові всі, напад починається раніше з бонусом) |
| **Tab / K / J** | боєць і спорядження / таланти / модернізація |
| **M** | карта · **Enter** чат · **Esc** меню · **F11** повний екран · **колесо** масштаб |

## Ігровий цикл

**Підготовка → Напад → Підготовка…** Тривалість підготовки задається в меню (1–15 хв).

- **Вогневі позиції** (до 25 рівня; з рівнем з'являються додаткові мішки, маскувальна сітка, бетонні блоки):
  - Кулеметне гніздо;
  - АГС (осколки + придушення);
  - Зенітна установка (кілька цілей, ×2.5 по повітряних);
  - ПТРК (ігнорує броню, ×1.6 по техніці);
  - Міномет;
  - Гаубиця.
- **Противник:**
  - піхота, мотоциклісти, FPV-дрони, БТР, ударні дрони, танки (з динамічним захистом), ремонтні машини;
  - кожна 10-та хвиля приводить важку ціль: **важкий танк**, **десантний транспорт** або **бойовий гелікоптер**.
- **Грінд за периметром:**
  - **Позиції ДРГ** у лісосмугах і місті. Після кожної зачистки противник повертається сильнішим, з кращими трофеями.
  - **Трофеї** п'яти рідкостей: зброя, захист, спорядження.
  - **Майстерні** на покинутих складах дають запчастини для **модернізації**.
- **Бійці:** однакові на старті, роль формують три гілки талантів (Штурмовик, Стрілець, Інженер). Рівень необмежений.
- **Пори року** змінюються кожні 5 хвиль: весна, літо, осінь, зима.
  - Природа реагує: восени жовтіє листя, взимку дерева голі й лежить сніг, після дощу земля мокра й блищить.
  - **Погода** змінюється кожні кілька хвилин і впливає на бій: туман і хуртовина зменшують дальність позицій, сніг сповільнює наземних ворогів, гроза заважає дронам.
- **Укриття:** будинки міста зупиняють кулі. Ховайтеся за стінами. ДРГ обходять будинки, щоб вийти на лінію вогню, і не стріляють у стіну.
- **Режими наведення:** у панелі позиції (ПКМ на ній) можна вибрати ціль: перший, останній, найсильніший, найслабший, найближчий.
- **Розвідка:** під час підготовки видно склад наступної хвилі, нові типи ворогів позначені «НОВЕ».
- **Якщо штаб знищено:** −25% коштів і запчастин, хвиля повторюється, решта прогресу лишається.
- **Складність** (на старті) визначає ріст сили противника: ≈ +7% / +9% / +11% за хвилю.

## Ресурси

Текстури, HDRI-небо та моделі оточення взято з [Poly Haven](https://polyhaven.com) за ліцензією **CC0**. Їх завантажує `scripts/fetch-assets.mjs`, а `scripts/optimize-models.sh` спрощує під легку гру. Бійців, техніку й вогневі позиції зібрано процедурно з фототекстурами. Звук синтезується в реальному часі.

Тести: `npm test` (рух по маршруту, наведення, колізії й укриття, тряска камери).

```
electron/  – вікно програми, перша копія запускає сервер
server/    – авторитетна симуляція, мережа (WebSocket), збереження, погода
shared/    – баланс і формули
client/    – 3D (Three.js), ефекти, інтерфейс, звук; client/assets — ресурси
```
