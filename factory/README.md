# Потік

Гра про поселення: жителі видобувають, переробляють і переносять ресурси, будують і обороняються від хвиль. Працює офлайн і без встановлення: один `potik.exe`.
Задум і план описані в [DESIGN.md](DESIGN.md).

## Збірка

Потрібен Go 1.26+.

```sh
# Windows (з будь-якої ОС), версія = дата збірки
./build.sh

# тести симуляції
go test ./...
```

Збереження лежить у `%AppData%\Potik\solo.sav`, окремо для кожного акаунта Windows. «Почати заново» в меню (або `potik.exe -new`) переносить поточний світ у резервну копію `solo.sav.<дата>.bak`; зберігаються 5 останніх.

## Оновлення

Поклади `potik.exe` у будь-яку папку (можна спільну для кількох акаунтів). При запуску гра копіює себе в `%LocalAppData%\Potik\bin` і працює звідти, тож файл у папці ніколи не зайнятий. Щоб оновити, просто заміни `potik.exe` новим. Наступний запуск підхопить нову версію, а запущена гра помітить заміну й запропонує «Перезапустити з оновленням» у меню (Esc).

## Структура

- `internal/sim`: симуляція (світ, поклади, жителі й логістика, машини, бої, збереження), без графіки.
- `internal/game`: рушій Ebitengine: камера, малювання, керування, інтерфейс.
- `internal/launch`: запуск з копії й оновлення заміною файлу.
- `cmd/potik`: точка входу.
