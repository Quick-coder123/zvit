# Потік 3D (прототип)

Нова версія гри в low-poly 3D. Зараз це візуальний прототип: ярусна долина з річкою, ліс, кілька будівель і камера, яку можна обертати, нахиляти й наближати.

Керування: WASD — рух, Q/E — поворот на 45°, права кнопка миші — вільний поворот і нахил, R/F — нахил, колесо — масштаб, середня кнопка — перетягування.

Збірка під Windows:

```sh
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/potik3d.exe ./cmd/potik3d
```

Рендер власний: Ebitengine не має буфера глибини, тому сцена малюється від дальніх клітинок до ближніх (painter's algorithm) з пласким затіненням граней. Так він працює й через RDP без відеокарти.
